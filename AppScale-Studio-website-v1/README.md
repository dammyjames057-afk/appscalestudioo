# AppScale Studio

Static marketing website for an app growth / digital marketing studio.

## Deploy to Netlify
1. Create a GitHub repository and upload these files.
2. In Netlify, choose Add new project > Import an existing project.
3. Select the GitHub repository.
4. Build command: leave blank.
5. Publish directory: `/` (root).
6. Deploy.

## Before publishing
- Replace `hello@appscalestudio.com` with your real business email.
- Confirm that every portfolio item is a project you are entitled to describe as past work.
- Replace illustrative campaign analytics with genuine project evidence when available.
- Add your real social links and privacy/terms pages.
- Add more portfolio cards later as new projects are documented.

## Included assets
- Client feedback screenshots supplied by the user.
- Campaign dashboard marked as illustrative.
